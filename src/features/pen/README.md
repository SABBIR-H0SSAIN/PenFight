# Pens

`Pen.tsx` owns one player's model and accepts `slot`, `model`, optional `color`, and the loaded `matadorTemplate`, `smoothyTemplate`, `allTimeTemplate`, and `iTeenTemplate`. Its registered handle lets the controller apply physics snapshots without React rendering every frame.

`ui/PenSelector.tsx` is the controlled picker reused by all mode screens; `ui/PenPreview.tsx` and `ui/PenPointer.tsx` supply menu visuals. `src/config/pens.ts` owns metadata, balance and custom palettes. `catalog.js` re-exports the resolved configuration for menus and physics; `types.ts` derives `PenKind` from the raw catalogue keys.

`ui/pen-selection.css` sizes cards against each selector's available width with container queries. Wide selectors use multiple columns with previews above the text; narrower selectors use readable full-width rows, and very narrow split panels stack the preview above the name. Custom-color controls wrap within the same container. The main-menu pointer renders the supplied Matador High School GLB into a cached transparent image in the active button's reserved slot; narrow screens show only the arrow.

`models/pen-models.js` handles materials, texture caching, model selection, transforms and disposal. `standard-pen.js`, `matador-high-school.js`, and `matador-smoothy.js`, `matador-all-time.js`, and `matador-i-teen.js` contain the actual mesh construction. To add a pen, add its entry in `src/config/pens.ts`, style and builder. Test both model geometry and human-vs-AI selection. Repeated selections keep the same meshes; changed selections release the previous geometry.

Fall orientation comes from the physics recording: the holder rotates about the recorded desk-edge normal, retaining pen yaw and barrel roll. The model's convex cross-section is cached when built; its lowest rolled cap/clip point sets resting height. This keeps original proportions and prevents trim sinking into the desk. `tests/edge-fall.test.js` checks real mesh triangles against the desktop during recorded edge/corner falls, including sliding and spinning departures.

Matador High School uses the user-supplied `public/models/pens/matador-hi-school.glb`; Smoothy uses the supplied capped `public/models/pens/matador-smoothy.glb`. `models/assets.js` owns their versioned URLs, which the page preloads before the game bundle runs. Update its SHA-256 prefix when replacing the GLB; `tests/loading.test.js` checks the version. Versioned requests receive immutable browser caching. `models/load-pen-assets.js` caches each loading promise; `GameScene` loads all four in parallel and waits for them before mounting the scene. `matador-high-school.js` clones resources per player, aligns the authored X axis with physics, fits its length and cross-section to the catalogue dimensions for board visibility, and recolours only the barrel materials. Keep the printing, nib and translucent cap materials intact. `matador-smoothy.js` aligns the source -Y tip with +X, fits its existing physics dimensions, and recolours mint plastic while preserving embedded black printing with an ink mask. `clone-pen-template.js` gives each player independent geometry, materials and textures for all supplied GLBs. The templates are never rendered, and each player's cloned resources can be disposed independently.

Mouse, touch and stylus safety tests cover every catalogue model under every camera preset on narrow/wide canvases and at zoom limits. Saved IDs and custom colours must be strings; coercible arrays are rejected during hydration. Run scene/engine/match-option/gesture tests after changing dimensions, and inspect printing/cap/readability in the browser. [Testing guide](../../../docs/testing.md).

Matador All Time uses the supplied mobile posted GLB at `public/models/pens/matador-all-time.glb`, with matching colour selection for the cap, rear plug and lower tip housing. Its builder aligns -Y to game +X and uses a clear barrel/grip and dark refill, while preserving the steel nib and embedded branding. [Physics research and tuning](../../../docs/pen-physics.md) distinguishes sourced product details from estimated game parameters.

Matador i-teen uses the posted gel-pen GLB at `public/models/pens/matador-i-teen.glb`. Its builder applies the selected colour only to the main barrel, ending at the clear grip. A narrow neutral refill remains visible through the grip and nose; the stainless writing point and tiny dark writing ball are independent of barrel colour. The clear shell, dotted grip, rear cap and white printing stay intact. Physics estimates and the distinction between gel and ballpen sources are recorded in the physics notes above.

The i-teen model is refined against [Matador's own product photograph](https://eshop.matador.com.bd/assets/images/product_image/1570346461hRUg0RD.png) and [additional Matador distributor photographs](https://www.maxindustry.pk/products/matador-iteen-gel-pen). Its clear cap shell occupies about 27% of total length and is about 1.12 times the barrel diameter. The cap stays anchored at the rear, with the original overall fitting retained. `matador-i-teen.js` also refines the grip width, flattens the moulded dots, tapers the clip, shortens the tail plug and compacts the white branding near the rear. Clear plastics use single front faces and moderate opacity so the cap, clip, grip and nose remain visible against the desk. Inner walls have only a faint tint, preventing overlapping transparent layers from bleaching the coloured core. All edits apply to player-owned cloned resources, preserving the source GLB and other pens. Proportions are estimated from photographs, not manufacturer CAD dimensions.

All Time's dark refill extends through the full clear grip and tapers into the steel nib, with a small overlap at the nib junction. The nose feeder uses the same dark material so the visible ink path has no coloured gap.

`i-teen-geometry.js` rebuilds the cap's closed faceted crown, the smoothly curved pocket clip and rounded hook, the clear nose taper and the stepped stainless point. The cap is posted with its clip to the side. Angle-dependent edge reflections keep the transparent moulding visible while the coloured core remains readable. The local GLB stays the source for the barrel, grip, printing and assembly; all replacements are player-owned and independently disposable.

All Time's outer barrel and grip use moderate translucency (40% barrel opacity) so their moulded surfaces remain visible at normal game zoom while the dark refill can still be seen inside. The barrel stays neutral; selected colours remain confined to the end parts.

i-teen's display cross-section has a modest 12% width increase for readability against product-photo proportions. The length, cap-to-barrel ratio, custom colours and physics settings are retained; the cap, grip and nib widen together so no individual part becomes oversized.
