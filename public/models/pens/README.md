# Pen assets

`matador-hi-school.glb` is the user's supplied Matador High School model with its cap on the back, originally named `matador_hi_school_cap_on_back.glb` (the available download copy had the suffix ` (1)`).

The game serves this file at `/models/pens/matador-hi-school.glb`. Its long axis is X. The renderer scales it uniformly and uses the authored material names to identify the recolourable barrel. Before replacing it, check alignment, table contact, printing, translucent cap, and both player colours. Provenance here records the supplied asset; it does not grant an additional licence.
