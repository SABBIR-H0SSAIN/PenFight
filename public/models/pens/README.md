# Pen assets

`matador-hi-school.glb` is the user's supplied Matador High School model with its cap on the back, originally named `matador_hi_school_cap_on_back.glb` (the available download copy had the suffix ` (1)`).

The game serves this file at `/models/pens/matador-hi-school.glb`. Its long axis is X. The renderer aligns it to X and fits its length and cross-section to configured playable dimensions, then uses the authored material names to identify the recolourable barrel. Before replacing it, check alignment, table contact, printing, translucent cap, and both player colours. Provenance here records the supplied asset; it does not grant an additional licence.

Default playable dimensions and colour options are in `src/config/pens.ts`; geometry fitting is in `src/features/pen/models/matador-high-school.js`. The geometry tests check fit, preserved printing/cap materials, independent colours and disposal. Asset provenance is unchanged by configuration overrides.

`matador-smoothy.glb` is the unmodified `MATADOR_Smoothy_Capped.glb` from the user's `MATADOR_Smoothy_Penfight_3D_Assets.zip`. It replaces the previous procedural Smoothy mesh. This full-pen variant has its cap on the back, embedded barrel printing, raised cap lettering and a separate steel refill/rollerball. Its source axis is Y with the writing tip along -Y. `matador-smoothy.js` turns the tip toward game +X, keeps the printing face up, and fits the source to the existing playable length/radius. Only mint plastic is recoloured; the printed material uses the embedded texture as an ink mask to preserve lettering under custom colours. The uncapped and cap-only variants are not used by gameplay.

`matador-all-time.glb` is the unchanged `matador_all_time_mobile_posted.glb` from the user's `matador_all_time_complete_pack.zip`. Its cap is posted at the rear; the source -Y writing tip maps to game +X and +Z branding faces up. The source model's metallic barrel/grip materials are changed to neutral transparent plastic at runtime, exposing a dark refill. The selected colour affects the cap/clip, rear plug and lower tip housing, including source amber trim. Only the actual nib remains steel; embedded white branding is preserved. The 11,942-triangle mobile variant reduces cost compared with the detailed 42,350-triangle posted model. Physics values are game estimates documented with research sources in `docs/pen-physics.md`.

`matador-i-teen.glb` is the unchanged `matador_i_teen_posted.glb` from the user's `matador_i_teen_game_assets.zip` found in Downloads. The supplied model represents the gel variant, with its cap posted on the back. Its source -Y writing tip maps to game +X and +Z branding faces up. The coloured core can be changed per player. Runtime refinements match reference photos: close-fitting cap, shallow grip dots, tapered clip, compact lettering and clearer plastic materials. The steel tip and embedded white lettering texture are preserved. The model contains 112 meshes and 9,348 triangles; dimensions are approximate. See `docs/pen-physics.md` for variant-specific research and explicitly estimated physics values.
